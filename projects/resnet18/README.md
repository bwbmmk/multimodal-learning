# 手写 CIFAR ResNet18

在原 CIFAR-10 数据和训练/验证/测试流程上，改为手写 BasicBlock 和四阶段残差网络。保留独立验证预处理、验证集选最佳模型、最后加载最佳权重评估测试集的流程。

目前有两轮实验：50 轮基线（2026-11-03）和 100 轮改进版（2026-11-10）。本页表格默认指改进版，基线数值见 [CIFAR-10 实验记录](../../docs/cifar10-experiments.md) 实验四。

## 文件

- `model_resnet18.py`：模型定义（`basicblock` + `ResNet` + `ResNet18()`），可导入，不会触发训练。
- `CIFAR-10_resnet18_train.py`：训练脚本（数据管道、混合精度、checkpoint），有 `if __name__ == "__main__"` 主入口保护。
- `training-log.txt`：50 轮基线的原始训练输出。
- `metrics.csv`：从基线日志提取的 50 轮指标。
- `training-log-100ep.txt`：100 轮改进版的训练输出（tqdm 进度条只保留统计字段）。
- `metrics-100ep.csv`：100 轮改进版的逐轮指标。

```bash
python projects/resnet18/CIFAR-10_resnet18_train.py
```

数据路径为 `D:/ai/cifar10_data/`，换机器前修改 `path`。导入模型时可将本目录加入模块路径，执行 `from model_resnet18 import ResNet18`。注意：捷径属性名是 `shortcut`，与 2026-11-03 旧权重里的 `shoutcut` 键名不一致，加载旧权重需要先做键名映射。模型为 CIFAR 输入改造版，不等同于 torchvision 的 ImageNet 标准入口；没有预训练权重。

## 结果和配置（100 轮改进版）

| 项目 | 数值 |
| --- | --- |
| 数据划分 | 45,000 / 5,000 / 10,000 |
| 输入 / 输出 | `[N,3,32,32]` / `[N,10]` |
| 残差块数量 | `[2,2,2,2]` |
| 参数量 | 11,173,962 |
| 优化器 | SGD(lr=0.1, momentum=0.9, weight_decay=5e-4) |
| 调度 / 训练 | CosineAnnealingLR(T_max=100)，100 轮，batch size 64 |
| 损失函数 | `CrossEntropyLoss(label_smoothing=0.1)` |
| 数据增强 | RandomCrop(32, padding=4)、RandomHorizontalFlip、RandomErasing(p=0.5) |
| 归一化 | CIFAR-10 真实 mean/std `(0.4914,0.4822,0.4465)/(0.2470,0.2435,0.2616)` |
| 精度 | AMP（fp16 + GradScaler） |
| 最佳验证 | 第 98 轮，96.10%，loss 0.6027 |
| 最终测试 | 95.29%，loss 0.6159 |
| 权重 | `../../weights/cifar10/cifar10_resnet_best_model_1110_0104.pth` |

基线对照：50 轮、batch 128、普通交叉熵、mean/std=0.5，第 48 轮验证 94.80%，测试 93.91%。两轮相比测试提高 1.38 个百分点，但多个因素同时改变，不能归因到单一技巧。

注意：标签平滑会改变 loss 口径，即使完全预测正确也有约 0.4 的下限，所以改进版的 0.6027 / 0.6159 不能与基线的 0.2019 / 0.2212 直接比较；能横向比的是准确率。

## 张量形状

```text
输入             [N,3,32,32]
入口 / layer1    [N,64,32,32]
layer2           [N,128,16,16]
layer3           [N,256,8,8]
layer4           [N,512,4,4]
全局平均池化      [N,512,1,1]
展平 / 分类       [N,512] → [N,10]
```

主分支与捷径逐元素相加；形状改变时，捷径用 1×1 卷积和 BN 匹配通道、空间尺寸。1×1 卷积也学习通道组合。`expansion=1` 表示输出相对基础通道数的倍率，不代表输入输出通道永远一致。结构知识点整理见 [ResNet18 结构笔记](../../docs/resnet18-notes.md)，训练脚本里的注释整理见 [训练流程与技巧笔记](../../docs/training-notes.md)。

## 如何理解泛化差距

基线：第 40→50 轮验证损失从 0.2413 降至 0.2015；第 48→50 轮验证准确率只下降 0.16 个百分点。训练准确率约 99.85%，说明训练拟合充分，但不能只凭与验证集的差距就断言继续训练已明显损害泛化。训练指标还包含随机增强和训练模式，与固定检查点的验证测量条件不同。

改进版：末期训练准确率 98.28%、验证 95.74%，差约 2.5 个百分点，属于轻度过拟合；验证曲线中段波动较大（lr=0.1 + batch 64 步长较大），后期稳定在 95.6~96.1%。

两轮实验都只固定了数据划分种子 42，没有多种子结果；也不能从 CNN→ResNet 的组合变化中隔离残差连接的单独贡献。
