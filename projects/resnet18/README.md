## 张量形状

```text
输入             [N,3,32,32]
入口 / layer1    [N,64,32,32]
layer2           [N,128,16,16]
layer3           [N,256,8,8]
layer4           [N,512,4,4]
全局平均池化      [N,512,1,1]
展平 / 分类       [N,512] → [N,10]
```

主分支与捷径逐元素相加；形状改变时，捷径用 1×1 卷积和 BN 匹配通道、空间尺寸。1×1 卷积也学习通道组合。`expansion=1` 表示输出相对基础通道数的倍率，不代表输入输出通道永远一致。

## 如何理解泛化差距

第 40→50 轮验证损失从 0.2413 降至 0.2015；第 48→50 轮验证准确率只下降 0.16 个百分点。训练准确率约 99.85%，说明训练拟合充分，但不能只凭与验证集的差距就断言继续训练已明显损害泛化。训练指标还包含随机增强和训练模式，与固定检查点的验证测量条件不同。

本次仅固定了数据划分种子 42；没有多种子结果，也不能从 CNN→ResNet 的组合变化中隔离残差连接的单独贡献。标签平滑、Dropout 等改进没有在本次实验中实施。
