# CIFAR-10 本地演示

把训练好的 CIFAR-10 模型搬到浏览器里跑：选一张示例图，或者拖入自己的图片，能看到模型给出的分类和置信度。

**整个过程完全在本机进行**，图片不会上传，也不需要联网（`vendor/` 里的推理运行时已经放在本地）。

## 怎么打开

双击 `start.bat`。它会启动本地服务、自动打开电脑浏览器，同时在窗口里打印**手机访问地址和二维码**。

如果窗口一闪而过或者浏览器没打开，手动跑：

```bash
cd projects/cifar10-demo
py tools/serve.py
```

然后访问 <http://127.0.0.1:8000>。

> 不能直接双击 `index.html`。浏览器的安全策略不允许 `file://` 页面加载 WASM 和 ONNX 模型，必须通过本地 HTTP 服务打开。

## 在手机上用

**手机和电脑连同一个 Wi-Fi**，然后：

1. 双击 `start.bat`
2. 电脑浏览器打开后，**页面右上角就有一张二维码**，手机直接扫它
3. 扫不动的话，命令行窗口里也打印了地址，手动输入 `http://192.168.x.x:8000` 也行

二维码是启动时按当前 IP 现生成的，换 Wi-Fi 后重启一次 `start.bat` 就会更新，不会指向旧地址。

手机端和电脑端是同一份页面，会自动切成单列布局；选完图片后页面会自动滚到结果卡片，不用自己往下找。

**连不上怎么办**，按这个顺序排查：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 手机一直转圈打不开 | Windows 防火墙没放行 | 首次运行会弹提示，选「允许访问」并勾上「专用网络」。没弹的话用管理员运行窗口打印的那行 `netsh advfirewall ...` |
| 换了个 Wi-Fi 就打不开 | IP 变了 | 重开 `start.bat`，用新打印的地址 |
| 手机用的是流量 | 不在同一个局域网 | 关掉流量，连上同一个 Wi-Fi |
| 电脑连的是校园网/公司网 | 网络可能开了设备隔离 | 换成手机热点，让电脑连手机热点，再用打印出的地址 |

IP 地址每次换网络都可能变，所以别存书签记 IP，**每次都从页面上那张二维码扫**。

> 想在外面（不同网络）也能访问，就不是局域网的事了，需要把服务放到公网：临时可以用 Tailscale 这类组网工具，长期可以用内网穿透或直接部署到静态托管。有需要再说。

## 页面里有什么

- **示例图**：从 CIFAR-10 测试集每类挑一张，10 类各一张。这些示例从各类预测正确的样本中按置信度 25% 分位规则选取，仅供展示，不代表总体难度。
- **自己的图片**：手机上点一下会弹出「拍照 / 相册」，电脑上可以点击选择或直接拖进来。**iPhone 的 HEIC 原图浏览器解不了，用相册里的「导出为 JPG」，或者直接拍照上传。**
- **非正方形图片**：默认「中心裁剪」，保留画面中心的正方形区域；也可以切到「直接拉伸」。两种模式的结果会实时变化，可以对比看看裁剪对预测的影响。
- **32×32 输入预览**：左边是原图，右边是**真正送进模型的**那张 32×32 小图。这是整个演示里最值得看的部分——很多"模型怎么猜错了"的疑问，看一眼这张小图就明白了。

## 图片是怎么变成 `[1, 3, 32, 32]` 的

```text
原图（任意尺寸）
  → 中心裁剪成正方形（或直接拉伸）
  → 缩放到 32×32
  → 像素值 0~255 除以 255，变成 0~1
  → (x - 0.5) / 0.5，映射到 -1~1
  → 排成 [1, 3, 32, 32]
  → 模型输出 10 个 logits
  → softmax 得到 10 个类别的概率
```

RGB 通道排列和归一化对应训练代码；任意上传图与 CIFAR-10 训练数据仍可能存在明显分布差异。

## 模型

- 权重：`multimodal-learning` 仓库里第 48 轮 ResNet18 最佳验证模型（验证 94.80%，测试 93.91%）
- 结构：手写 CIFAR ResNet18，四阶段各两个 BasicBlock，全局平均池化，11,173,962 个参数
- 格式：`model.onnx`，42.6 MiB，opset 17
- 推理：ONNX Runtime Web，WASM 后端，单线程，耗时由页面现场测量，取决于设备和浏览器，不沿用旧 CNN 的测量值

## 一个诚实的提醒

这个模型是**在 CIFAR-10 的 10 个类别上训练的**：飞机、汽车、鸟、猫、鹿、狗、青蛙、马、船、卡车。

它能做的只是"把图片归到这 10 类里最像的一类"。你给它一张人像、一张风景、一张美食，它也会很自信地告诉你这是"狗"或"卡车"——这不是 bug，是它根本没见过别的类别。所以拿自己的照片玩的时候，看**置信度分布**比看结论更有意思。

## 关于二维码

`start.bat` 里的二维码依赖 Python 的 `qrcode` 包，已经装好了。换电脑的话：

```bash
py -m pip install qrcode
```

没装也不影响使用，只是不显示二维码，手动输入地址就行。

## 仓库内重新导出 ResNet

在仓库根目录执行（需安装 `onnx`；二维码功能可选安装 `qrcode`）：

```bash
python projects/cifar10-demo/tools/export_model.py --weights weights/cifar10/cifar10_resnet_best_model_1103_2241.pth --data-root D:/ai/cifar10_data --output projects/cifar10-demo --best-epoch 48 --validation-accuracy 0.948 --reported-test-accuracy 0.9391
```

导出脚本只导入 `projects/resnet18/model.py`，不会启动训练。原本地目录也支持 `CIFAR-10/resnet_model.py`。换成后续新权重时，应填写对应的真实指标，不能沿用本次参数；这些指标参数也可以省略。

元数据记录模型内容哈希、字节数、checkpoint 哈希和导出时的测试复评。前端以内容哈希区分模型缓存，`samples.json` 使用 `no-store`，HTML 的应用脚本 URL 同步版本。
