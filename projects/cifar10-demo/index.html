它只学过飞机、汽车、鸟、猫、鹿、狗、青蛙、马、船和卡车。其他图片也会被强行分到其中最相似的一类。

看看图片是怎样变成 [1, 3, 32, 32] 的
  1. 调整尺寸：中心裁剪或直接拉伸为 32 × 32 像素。
  2. 读取 RGB：每个像素取出 R、G、B 三个 0～255 的数值。
  3. 转换为张量：先除以 255，再执行 (x - 0.5) / 0.5。
  4. 调整排列：从按像素排列转成 CHW，即 3 个通道 × 32 行 × 32 列。
  5. 增加批次维：最终形状为 [1, 3, 32, 32]，送入 ONNX 模型。

网页中的预处理与训练代码里的 ToTensor() 和 Normalize([0.5, 0.5, 0.5], [0.5, 0.5, 0.5]) 对应。
